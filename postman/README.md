# ShopHub Postman Collection

Import these files into Postman:

1. `ShopHub-Ecommerce.postman_collection.json`
2. `ShopHub-Local.postman_environment.json`

Use the `ShopHub Local` environment. Run `Authentication > Login` first to store `token` and `refreshToken` for protected requests.

The collection groups actions by website feature:

- Authentication
- Products
- Cart
- Payments
- Notifications and Admin Approval Actions
- Common Error Response Examples

Each request includes sample JSON payloads and response examples for success and relevant error cases.
